# Specimen implementation guides

These guides identify existing implementation files, anatomical constraints, motion behavior and verification entry points. The companion research dossiers preserve the underlying sources and limitations.

This index covers existing standalone studies, not the full mission or the complete implemented catalog. Older specimens can have references in [botanical references](../botanical-references.md) or the shared [expanded forms](../architecture/expanded-forms.md) study without a standalone dossier. Missing per-flower research remains a documentation gap; inventory presence is not implementation or scientific validation.

The implemented collection is defined by [the catalog](../../lib/flowers/catalog.ts). The [global target inventory](../FLOWERS.md) tracks the broader mission to create every flower. See [development](../development.md) for commands and inspection procedures, and [the companion index](../research/README.md) for the other view of these studies.
